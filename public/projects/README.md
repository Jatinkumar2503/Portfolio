# Project images

Drop your real project screenshots here and keep the same names as below for the fastest setup:

- nexus-ai.png
- prajna.png
- pragati-ai.png

The portfolio is already wired to load these files from the public/projects folder.

If you prefer different filenames, update the `previewImage` paths in `data/projects.ts` to match the new file names.

Recommended:
- prefer real project screenshots or system dashboard captures
- use PNG or JPG for best compatibility
- keep a consistent aspect ratio for the project cards
- use the same naming for each project to make updates easy
